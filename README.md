# AERO · Cessna 172

Fly the AERO Cessna 172S Skyhawk SP in your browser, with a glass-cockpit panel,
a GI 275-style attitude indicator, a clickable 172S startup checklist, a voice coach
(with mute), and Beginner / Realistic modes.

**Play:** https://00ainick-cmd.github.io/aero-c172-flight/

Needs a desktop browser with WebGL 2.

This repository holds only the built static site that GitHub Pages serves.
