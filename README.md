# AERO · Cessna 172

Fly the AERO Cessna 172S Skyhawk SP in your browser with a glass cockpit and GI 275-style attitude indicator. Launch and reset start on the runway with the engine running and avionics ready. No preflight checklist or coaching voice. Beginner / Realistic is available in the O controls bar.

**Play:** https://00ainick-cmd.github.io/aero-c172-flight/

Needs a desktop browser with WebGL 2.

This repository holds only the built static site that GitHub Pages serves.
Source: https://github.com/00ainick-cmd/aero-c172-sim (private).
